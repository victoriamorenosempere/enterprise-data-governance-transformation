Step 01
📤 Data query
Sustainability team initiates request
No request template:Ad hoc emails sent to each source — no standard fields, no agreed scope, no confirmation of receipt No SLA:No deadline attached · no escalation path · no tracking of who has responded · process cannot start until all data arrives Missing data discovered late:Incomplete submissions only identified at consolidation — 1–2 weeks after request sent
request sent to three disconnected sources
Step 02
🏗️ Data sources
Three disconnected systems · no standard protocol
SAP ERP
Energy, materials, logistics, production volumes per plant. Not automatically exported — requires manual SAP query.
Staff logs into SAP → manual export → CSV or Excel → copies required fields → sends by email
Factory / Plant operational
Each site: water, waste, on-site emissions. Separate local systems — some Excel, some databases, some paper typed up.
Site coordinator exports from local system or manually types data into Excel → sends as email attachment
Third-party data
Logistics partners, suppliers, energy companies. Fuel consumption, materials, utility bills. Arrive as email attachments.
Third party sends in their own format (Excel / PDF / CSV) → team manually re-enters relevant figures
data retrieved — numerous separate Excel files, CSVs and attachments land in inbox
Step 03 · ~Wk 1–2
📥 Data collection & retrieval
Files received · no standard format
⚠ No standard format:Factory A → kWh · Factory B → MWh · Factory C → GJ · manual conversion required · conversion errors go undetected ⚠ No standard scope:"Emissions" means different things to different sites — Scope 1 only? Grid electricity? Fleet? No definition written down ⚠ No SLA — delays cascade:Some sites respond in 2 days · some take 2 weeks · entire process blocked waiting · no escalation possible ⚠ Missing data discovered late:Incomplete files only identified when consolidating — 1–2 weeks later · re-request required · further delay added
Damage quantified
~70%of submissions contain at least one unit inconsistency requiring manual correction
~2 wksaverage time lost waiting with no SLA · process fully blocked
~40%of cycles delayed by missing data discovered only at consolidation
staff manually copies all files into one master spreadsheet
Step 04 · ~Wk 2–3
📊 Data consolidation
Master spreadsheet built by copy-paste
⚠ No lineage — audit trail lost:Once pasted, the row's origin is permanently severed — no record of which factory, which export, which date it came from ⚠ Version chaos:Files saved as v1, v2, FINAL, FINAL_USE_THIS · multiple people may work from different versions simultaneously ⚠ Silent Excel errors:Wrong tab selected · formulas shift when rows inserted · thousands vs millions mismatch · errors invisible until stakeholder review
Damage quantified
~60%of consolidation errors are silent — not caught until stakeholder review weeks later
~1.5 daysaverage manual effort per consolidation cycle for one person
consolidated data prepared — calculations applied

🧮 Calculation & preparation
Emission factors applied via Excel formulas
⚠ Undocumented logic:Emission factor buried in cell F4 tab "Factors" · never documented · may have been updated without record · no one else knows it exists ⚠ Key-person dependency:One person built and understands this spreadsheet · if absent — process stops entirely · no SOP · no handover · no backup ⚠ No version history:Factors may have changed three times · no changelog · cannot confirm which version produced which output · regulatory exposure ⚠ Unit loss in copy-paste:Original Excel formulas that adapted units were severed during consolidation · technical factory/plant figures highest risk · ~90% probability engineer will flag
Damage quantified

Quality
Errors are silent and cumulative. Each step introduces new risk. By submission figures have passed through 4–5 manual transformations each carrying its own error probability.
Trust
Stakeholders cannot verify what they receive. Once challenged, data is presumed unreliable until proven otherwise. Each cycle starts with a trust deficit.
Compliance
